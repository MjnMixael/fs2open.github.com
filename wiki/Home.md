# Open Freespace Project Wiki

Documentation for the Open Freespace Project (OFP), a fork of FreeSpace Open with its own engine and QtFRED features. Everything from standard FreeSpace Open works in OFP as documented on the [FreeSpace Wiki](https://wiki.hard-light.net/); this wiki covers what OFP adds or changes.

## Getting Started

- [Using OFP with Knossos.NET](Using-OFP-with-Knossos.NET): switch a mod to the OFP engine in Knossos.NET
- [Building OFP on Windows](Building-OFP-on-Windows): set up Visual Studio, CMake and Qt to build OFP from source
- [Building OFP on Linux](Building-OFP-on-Linux) and [Building OFP on Mac](Building-OFP-on-Mac): the same for Linux and macOS
