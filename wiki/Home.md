# Open Freespace Project Wiki

Documentation for the Open Freespace Project (OFP), a fork of FreeSpace Open with its own engine and QtFRED features. Everything from standard FreeSpace Open works in OFP as documented on the [FreeSpace Wiki](https://wiki.hard-light.net/); this wiki covers what OFP adds or changes.

## Getting Started

- [Using OFP with Knossos.NET](Using-OFP-with-Knossos.NET): switch a mod to the OFP engine in Knossos.NET
- [Building OFP on Windows](Building-OFP-on-Windows): set up Visual Studio, CMake and Qt to build OFP from source
- [Building OFP on Linux](Building-OFP-on-Linux) and [Building OFP on Mac](Building-OFP-on-Mac): the same for Linux and macOS

## Features

- [OFP Features](OFP-Features): the catalog of what OFP delivers beyond stock SCP
  - [Engine Features](OFP-Engine-Features): what missions and mods can do in the game
  - [QtFRED Features](OFP-QtFRED-Features): editor enhancements
  - [Bug Fixes](OFP-Bug-Fixes): fixes to code OFP shares with SCP

## Documentation

- [OFP Tables](OFP-Tables): every table documented here, in alphabetical order
  - [ai.tbl](ai.tbl): AI classes
  - [ai_profiles.tbl](ai_profiles.tbl): AI profiles
  - [animation.tbl](animation.tbl): model subobject animations
  - [coordinate_points.tbl](coordinate_points.tbl): custom shapes for coordinate points (OFP only)
  - [editor.tbl](editor.tbl): editor settings and typed custom data fields for missions, campaigns and ships (OFP only, editor only)
  - [generated_nebula.tbl](generated_nebula.tbl): patterns and colors for the generated (FS1-style) background nebula (OFP only)
  - [props.tbl](props.tbl): prop classes (OFP additions so far)
  - [species.tbl](species.tbl): tech room intel entries (OFP additions so far)
- [OFP SEXPs](OFP-SEXPs): new SEXP operators and OFP changes to existing ones
- [OFP Lua Scripting](OFP-Lua-Scripting): Lua API added by OFP
