# OFP Features

The catalog of what OFP delivers beyond stock SCP, split into three pages:

- [Engine Features](OFP-Engine-Features): what a mission or mod can do in the game. Many of them also add editor support, but they are listed there because the game uses them.
- [QtFRED Features](OFP-QtFRED-Features): editor enhancements that change how you work in QtFRED, not what the game does.
- [Bug Fixes](OFP-Bug-Fixes): fixes for bugs in code OFP shares with SCP. Fixes to OFP's own features are covered by those features.

For the tables, SEXPs and Lua API these features add, see [Tables](Tables), [OFP SEXPs](OFP-SEXPs) and [OFP Lua Scripting](OFP-Lua-Scripting).
