Selection Groups

Found in the Select menu, on the right-click menu's Set Group, and on the Groups button in each object editor.

Selection groups are nine saved selections. Put a set of objects you often work on together into a group, and you can select all of them again with one keystroke instead of clicking each one in the viewport or the Scene Browser.

Ships, player starts, props, waypoint paths, jump nodes and coordinate points can all be in groups, and an object can be in several groups at once. A waypoint path is grouped as a whole: every point of a path is in the same groups.

Groups are an editor convenience only. They have no effect in the game, and they are not wings, layers or anything a SEXP can refer to. Unlike a layer, a group can take objects from several layers, and an object can be in more than one group. To select everything on a layer, right-click it in the Scene Browser and choose Select All.

Selecting a group

Choose Select › Select Group › Group 1 through Group 9, or press Ctrl+1 through Ctrl+9. The current selection is cleared and every object in that group is selected. Selecting a group with nothing in it clears the selection. Like Select All, it leaves out objects you couldn't click, such as those on hidden layers.

Adding objects to a group

Right-click an object in the viewport or the Scene Browser and open Set Group. Groups the selected objects are all in are checked, and a group only some of them are in is marked (some). Click an unchecked group to add all the selected objects to it, or a checked one to take them all out. Their other groups don't change. Right-clicking a wing or a waypoint path in the Scene Browser works the same way for the whole wing or path.

Seeing and changing an object's groups

Each object editor has a Groups button next to the layer. It shows the groups the object is in, for example Groups: 1, 4, or Groups: None. Click it for a checklist of the nine groups, then check or clear them.

When the editor is showing several objects, the button lists the groups all of them are in, followed by the groups only some of them are in, marked (some). In the checklist those are partly checked. A group you leave partly checked is left alone; check it to add all the objects to it, or clear it to take them all out.

Changing an object's groups this way doesn't touch any other object, so it's also how you take something out of a group or empty a group.

Undo

Set Group and changes made from the Groups button can be undone and redone like any other edit.

Saving

Groups are saved with the mission, in each object's entry, so they are still there the next time you open it. FRED2 can select and set groups of ships only, but it keeps the other objects' groups when it saves.

Older versions of QtFRED stored ship groups differently from FRED2, so groups set in a mission saved by one of them may now select the wrong ships. Set those groups again.
