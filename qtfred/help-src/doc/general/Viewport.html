Viewport

The main 3D view where mission objects are placed and arranged.

Creating objects

The toolbar dropdowns determine what type of object is created when you click in the viewport. Each dropdown is paired with its own modifier chord:

  • Ctrl+click - creates a ship from the Ships dropdown.
  • Ctrl+Shift+click - creates a prop from the Props dropdown.
  • Ctrl+Alt+click - creates a waypoint or jump node from the Other dropdown.

Selecting objects

  • Click an object to select it.
  • Click and drag on empty space to draw a selection box and select all objects within it.
  • Double-click an object to open its editor dialog.

The Select menu has:

  • Select All (Ctrl+A) - adds every object you could click to the selection.
  • Select None (Ctrl+Shift+A) - clears the selection.
  • Invert Selection (Ctrl+I) - selects the objects that aren't selected and deselects the ones that are.
  • Select Group › Group 1 to Group 9 (Ctrl+1 to Ctrl+9) - selects a selection group.
  • Select Layer - selects everything on a layer.
  • Select IFF - selects the ships and player starts of an IFF. Every IFF in the loaded tables is listed.
  • Select Ship Type - selects the ships and player starts of a type, such as fighter or bomber. Only the types the mission has are listed.
  • Select Object Type - selects all ships, player starts, props, waypoints, jump nodes or coordinate points.
  • Selection Lock (Space) - stops clicks in the viewport from changing the selection.
  • Lock Marked Objects / Unlock All Objects - makes the selected objects unselectable for the rest of the session, and undoes that.

The Select Group, Layer, IFF, Ship Type and Object Type items replace the selection. The Layer, IFF, Ship Type and Object Type items show how many objects they would select, and are grayed out when that's none.

Select All, Invert Selection and the select submenus leave out what you couldn't click: hidden objects, objects on hidden layers, object types (or ship IFFs) filtered out in the Layer Manager, and objects made unselectable by Lock Marked Objects.

Moving objects

Drag a selected object to reposition it in the mission.

Locking objects in place

Lock an object when it is placed where you want it and you don't want to nudge it by accident. A locked object keeps its position and orientation, but it can still be selected and everything else about it can be edited: its name, cues, flags, and so on.

  • What can be locked: ships and player starts, props, waypoint paths (the whole path, not single points), jump nodes, and coordinate points.
  • Locking and unlocking: use the lock checkbox under the Layer selector in the object's editor, or the lock button in the Layer Manager to lock or unlock everything on a layer at once. Both are undoable.
  • In the viewport: a locked object shows a small padlock beside its label. It shows and hides with the labels (View › Show Ship Info).
  • What it stops: dragging and rotating in the viewport, flying the object with the camera controls, the transform toolbar, the Object Orientation Editor, Level and Align, and the Wing Editor's Align Formation. Undo and redo still move locked objects back and forth.
  • Moving a group: when several objects are selected, the locked ones stay put and the rest move. If the object you are dragging or editing is locked itself, nothing moves, and the status bar says why.
  • Docked ships: docked ships can only move together, so if any ship in a docked group is locked, the whole group is held in place. When docking in Initial Status, the unlocked ship moves to the locked one; two held ships can't be docked to each other. When undocking with "move ships when undocking" on, the unlocked ship is the one moved clear.
  • Waypoint paths: a locked path's points stay where they are and Ctrl+Shift+drag can't insert new points into it. Points can still be deleted.
  • Copies: a Ctrl+drag copy of a locked object starts unlocked.

Locks are saved in the mission file. They are editor-only: the game ignores them, and a mission with locked objects needs FSO 26.1 or later to load.

This is not the same as Select › Lock Marked Objects, which makes objects unselectable until you use Unlock All Objects and isn't saved.

Duplicating objects

  • Ctrl+drag a selected object to duplicate everything that is currently marked. Ships, props, and jump nodes are cloned with all their editable fields preserved. Marked waypoints are copied into a new path that inherits the source path's color, layer, and line-drawing settings.
  • Ctrl+Shift+drag behaves the same as Ctrl+drag except for waypoints: each marked waypoint is inserted into its source path right after the original, extending the path rather than creating a new one. Useful when you want to add more points to an existing path without redrawing it. Other object types in the marked set are duplicated normally. Points can't be inserted into a locked path.

Context menu

Right-click anywhere in the viewport to open a context menu with options relevant to what was clicked. A plain right-click (without dragging) opens the menu; right-click and drag instead moves the camera (see below). Available options vary depending on whether you clicked an object, a specific object type, or empty space.

Camera controls

The camera orbits around a pivot point in the scene. Mouse controls move the camera without changing any mission data:

  • Middle-button drag - orbit (rotate) the camera around the pivot.
  • Shift + middle-button drag - pan the camera, sliding the view sideways and up/down instead of rotating.
  • Right-button drag - orbit the camera, the same as a middle-button drag. Shift + right-button drag pans. A right click that does not drag opens the context menu instead.
  • Mouse wheel - zoom the camera toward or away from the pivot.

Keyboard controls

The keyboard can also fly the camera around the viewport. The default bindings are:

  • A / Z - move forward / backward.
  • Numpad 1 / Numpad 3 - move left / right.
  • Numpad - / Numpad + - move up / down.
  • Numpad 4 / Numpad 6 - yaw left / right.
  • Numpad 2 / Numpad 8 - pitch up / down.
  • Space - toggle selection lock, which prevents clicks in the viewport from changing the current selection.

With Objects › Control Object on, the same keys fly the current object (and the other marked objects, following the transform toolbar's Pivot mode) instead of the camera; while viewing through a ship, they fly that ship. Each flight is one undo step, recorded once the object comes to rest.

All of these keys can be reassigned under File › Preferences › Controls. See the Preferences page for details.

Viewpoints

View › Viewpoint chooses what the viewport looks through: the editor Camera, the Current Ship, or the Cutscene Camera selected in a SEXP tree. Viewing through a ship uses the in-game field of view instead of the editor's narrower one, and a cutscene camera uses its own. Ctrl+Shift+V cycles through the ones available. See Cutscene Camera Preview for previewing and placing cutscene cameras.
