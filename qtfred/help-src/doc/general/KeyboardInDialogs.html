Keyboard in Dialogs

How the keyboard behaves in QtFRED's editor dialogs.

KeyWhat it does
Tab / Shift+TabMoves to the next or previous control. Buttons reached this way are outlined in the accent color, so you can see which one has focus. Multi-line text boxes (descriptions, briefing text, message text, notes) pass Tab on to the next control too; the Events editor's Advanced view and the Voice Acting Manager's script format keep Tab for typing a tab character.
EnterConfirms the field you are in, such as a typed number or name, but does not close the dialog or press OK. This keeps a keystroke meant for a field from applying and closing the editor mid-edit. To press a button with the keyboard, Tab to it and press Enter or Space. Small pickers and prompts (choosing a mission, entering a name) do accept on Enter.
EscCloses the dialog. Editors with unapplied changes ask first.
