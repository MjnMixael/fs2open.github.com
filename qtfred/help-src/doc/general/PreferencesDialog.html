QtFRED Help › Preferences

Preferences

Opens via Edit › Preferences.

Controls QtFRED editor settings. Changes take effect immediately; there is no Apply button.

General

Miscellaneous editor options. Hover over each setting for a tooltip description.

Autosave

QtFRED periodically saves a background copy of the mission you are editing so that work can be recovered after a crash. Autosaves are written to a separate autosave folder and never overwrite the mission file you are working on.

  • Autosave interval - how often, in seconds, the background save runs. The timer runs on its own; you do not need to trigger autosaves manually.
  • Offer autosave recovery - when enabled, opening a mission whose autosave copy is newer than the mission file prompts you to load the autosave instead. Disable this to always open the on-disk mission without being asked.

Grid

Configures the reference grid shown in the main viewport. You can set which world-space plane the grid lies on (XZ, XY, or YZ) and adjust the grid's center point to move it to a different position in the world. Use Reset grid to restore the plane and center to their defaults.

Controls

Allows remapping the default input controls, such as camera movement and viewport navigation. Hover over each entry for a description of what it does. The default keyboard bindings are listed on the Viewport page.

Placing Objects chooses which click places each kind of object in the viewport: Ship, Prop and Other (a waypoint, jump node or coordinate point, as set in the toolbar's Other dropdown). Each can be Ctrl+click, Ctrl+Shift+click or Ctrl+Alt+click, and no two share one: picking a click another kind uses swaps the two. The defaults are Ctrl+click for ships, Ctrl+Shift+click for props and Ctrl+Alt+click for other objects. Changing them can help where the desktop takes one of these clicks for itself, as some Linux window managers do with Ctrl+Alt+click.

Reset to Defaults restores the key bindings and the placement clicks.
