Layer Manager

Opens via View › Layer Manager.

Organizes mission objects into named layers. Layers are an editor-only concept and have no effect on mission gameplay. They exist purely to help manage visibility in the viewport while editing.

Layers tab

Lists all layers in the mission. Each layer has a checkbox; uncheck it to hide all objects on that layer in the viewport, check it to show them again. Newly placed objects are automatically assigned to the Default layer.

Use Add Layer to create a new layer. Use Rename Layer to rename the selected layer; every object on it is updated to the new name. Use Delete Layer to remove the selected layer, reassigning its objects to the Default layer. The Default layer cannot be renamed or deleted.

The lock button next to them locks or unlocks the position and orientation of every object on the selected layer (see Locking objects in place). Its icon shows the layer's current state:

  • Open padlock: nothing on the layer is locked. Click to lock it all.
  • Closed padlock: everything on the layer is locked. Click to unlock it all.
  • Faded closed padlock: only some objects are locked. Click to lock the rest.

The button is disabled for an empty layer. It sets each object's own lock, so an object moved onto a locked layer later is not locked by it, and one undo step reverses the whole change.

Filters tab

Works in conjunction with layers to provide additional visibility control. Allows hiding objects by type or by IFF team regardless of which layer they are on.

Hiding objects via layers or filters does not delete or disable them. Hidden objects are still present in the mission file and will function normally in-game.
