Reorder Objects

Opens via Tools › Reorder Objects.

Changes the order in which ships, wings, props, waypoint lists, jump nodes, and coordinate points are stored. That order is what gets written to the mission file, and it controls how each type is listed in order-based UI such as the Scene Browser. Reordering does not move anything in space, rename anything, or change any references. These objects are referred to by name everywhere else, so their references stay intact.

Moves apply immediately. There is no Apply or Cancel step: each move rewrites the stored order as soon as you make it, and closing the dialog keeps whatever order you have set.

Tabs

Each object type has its own tab. Switch tabs to reorder that type independently.

TabReorders
ShipsThe order of individual ships, including player starts.
WingsThe order of wings. Ships remain assigned to their wings; only the wing order changes.
PropsThe order of props.
Waypoint ListsThe order of waypoint paths. The waypoints within each path keep their own order.
Jump NodesThe order of jump nodes.
Coordinate PointsThe order of coordinate points.

Moving items

Select one or more items in the list, then use the buttons beside it to reposition them. Ctrl+click adds or removes an item and Shift+click selects a range, so the selection does not have to be in one piece. The buttons move all selected items together and are disabled when a move would have no effect (for example, Move up when the selection is already at the top). Each button press is a single undo step.

ButtonAction
Move to topMoves the selected items to the first positions, keeping their order.
Move upMoves each selected item one position earlier. An item already at the top stays, and so does a selected item right below it, so a block of selected items moves as one and the gaps between selected items are kept.
Move downThe same, one position later.
Move to bottomMoves the selected items to the last positions, keeping their order.

On the Ships tab, right-click a ship and choose Select Wing to select every ship in its wing, then move them as a group.
