Nameplate

Accessed via the Nameplate button in the Ship Editor. The button is available when a single ship is selected and its model has a texture named nameplate.

Puts a ship's name, hull number, or any other marking on its hull without making a texture for every ship. The nameplate fills the model's nameplate texture, either with text the game draws for this ship or with a texture file. It belongs to this ship only; other ships of the same class are unaffected.

Enable and source

  • Enable nameplate for this ship - turns the nameplate on. When it is off, the model shows its own nameplate texture.
  • Generate from text - the game draws the text below onto a transparent texture.
  • Use texture file - uses a texture you made instead.

If the mod has no font that can draw nameplates (see Font below), Generate from text is unavailable and only texture files can be used.

Generated Text

FieldDescription
TextThe text to draw, on one line. Text that does not fit is cut off at the edges of the texture; use the scale, letter spacing, and offset to fit it.
FontA font from the mod's fonts.tbl. TrueType fonts with +Auto Size are not listed: they are sized from the screen resolution, so a nameplate would look different in game than in the editor. (default font) uses the first font that is listed. If the mission names a font that is not loaded or not listed, it shows as (not available), the game uses the first listed font instead, and the Error Checker warns about it.
Font ScaleMultiplies the font's size. A font set to scale with the player's font size option or the screen resolution does not do so here, so a nameplate looks the same in the editor and in game.
Letter SpacingExtra space between characters, up to 100 pixels of the model's size either way (see Texture Size). Negative values tighten the text.
ColorThe text color, as red, green, and blue from 0 to 255. The swatch shows the result. White by default.
OffsetMoves the text this many pixels of the model's size from the center of the texture. Positive X moves it right and positive Y moves it down. Each can be up to 1024 either way.

Texture File

The name of the texture to use, without a file extension. Browse... fills it in from a file. Animated textures work as well.

Texture Size

The size in pixels of the texture generated text is drawn on, from 16 to 1024 per side. It starts at the size the model asks for (see For modelers below), or 256 by 64 if it asks for none, shown as Model size.

  • A larger size makes the text sharper without changing how it looks: the font scale, letter spacing, and offsets are measured against the model's size, so they grow with the texture. TrueType fonts gain the most; bitmap fonts only get blockier.
  • The model stretches the whole texture over its nameplate area, so a size with other proportions than the model's stretches the text. Keep the model's proportions, on by default, changes the other side to match. Turn it off to fit an older model whose nameplate area is not the shape its size suggests.
  • Reset to Model Size goes back to the model's size. A ship at the model's size follows the model if its size changes later; any other size is saved with the ship and kept if the ship changes class.

Things to know

  • The nameplate texture is always drawn with transparency, so generated text shows only the letters. A texture file should use its alpha channel the same way.
  • Changes show on the ship in the viewport as you make them; move the dialog aside to watch. Cancel puts the ship back as it was, and OK keeps the changes as a single Edit Ship Nameplate undo step.
  • The nameplate is included when the ship is duplicated.
  • Changing the ship's class keeps the nameplate and fits it to the new model. A model without a nameplate texture shows nothing, but the nameplate stays with the ship. This is also true in game, including when the player changes a ship's class in ship selection.
  • The nameplate texture does not appear in Texture Replacement; this dialog manages it.

Saving and compatibility

Nameplates are saved with the ship as a $Nameplate: section. How older builds see it depends on File › Save Format:

  • FS2 Open - the mission requires FSO 26.1 or later.
  • FSO Compatibility Mode - a texture file nameplate is saved as an ordinary texture replacement of the nameplate texture, which every build reads. Generated text is saved so that older builds skip it.
  • FS2 Retail - nameplates are not saved.

For modelers

Give the part of the hull that carries the nameplate a texture named nameplate. To choose the size of generated nameplates for the model, add these to the properties of any submodel, in pixels from 16 to 1024:

$nameplate_width=512
$nameplate_height=128

Match the proportions of the area the nameplate texture covers in the UVs, or the text comes out stretched.
