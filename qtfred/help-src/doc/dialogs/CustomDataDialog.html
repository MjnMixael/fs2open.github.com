Custom Data

Accessed via Custom Data in the Mission Specs dialog, the Campaign Editor, or the Ship Editor.

Attaches arbitrary key-value pairs to a mission, campaign, or ship. Custom data has no built-in effect on gameplay; it is intended to be read by Lua scripts and SEXPs that know to look for specific keys. See Custom Data in Concepts for the full picture, including how per-domain schemas are defined.

Schemas and pre-defined keys

An editor-defined schema (from editor.tbl) or a script calling mn.addDefaultCustomData(key, defaultValue, description) can register the keys an editor is expected to use. Registered keys drive three conveniences in this dialog:

  • The Key field auto-completes registered key names.
  • The value editor adapts to the key's declared type (see below).
  • The Description box shows the description registered for the selected key, or No help text provided if none was registered.

When no schema applies, every entry is treated as a free-form string. For the mission domain, any registered key not already present is added automatically when the mission is opened, so the expected entries exist without being created by hand.

Type-aware value editing

TypeValue control
string (or unregistered)A plain text field.
intA text field that only accepts whole numbers.
boolA drop-down offering true or false.

Click Reset to restore the value editor to the selected key's schema default. Reset is available only for keys that have a registered default.

Adding an entry

Fill in the Key and Value fields and click Add to create a new entry. Values are validated against the key's type before being added.

Editing an entry

Select an entry in the list to load it into the Key and Value fields. Modify the fields as needed and click Update to apply the changes.

Removing an entry

Select an entry in the list and click Remove to delete it.
