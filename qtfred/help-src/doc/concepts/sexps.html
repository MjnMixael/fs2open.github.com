SEXPs

A SEXP (Symbolic EXPression) is the scripting language built into FreeSpace missions. Every condition, trigger, and action in a mission — from checking whether a ship has been destroyed to playing a message — is expressed as a SEXP tree.

Structure

SEXPs use a Lisp-style prefix notation enclosed in parentheses:

(operator argument1 argument2 ...)

Operators can be nested, so arguments can themselves be SEXPs:

(when
    (is-destroyed-delay 0 "Epsilon 1")
    (send-message "" "Mission-Complete" "Command")
)

Here when is the top-level operator. Its first argument is a condition (is-destroyed-delay) and its second argument is an action (send-message). When the condition becomes true the action fires.

Where SEXPs appear

SEXPs are used in:

  • Mission Events — the primary place to author SEXP logic; see the Mission Events dialog.
  • Mission Goals — the completion condition for each goal; see the Mission Goals dialog.
  • Ship arrival/departure cues — conditions on when ships enter and leave the mission.
  • Briefing and debriefing — stage-change conditions.

Editing SEXPs in QtFRED

The same SEXP tree editor is used wherever QtFRED edits a condition or action: the Mission Events and Mission Goals dialogs, ship and wing arrival and departure cues, and the briefing, debriefing, cutscene and campaign branch conditions. Right-click any node in the tree to add, replace, or remove operators and arguments. Hover over an operator name for a brief description of what it does.

Search for Replacement

Select a node and press Space or Ctrl+S (also Search for Replacement in the right-click menu), or double-click a node that has nothing to expand. A search box opens with a list to filter as you type. What it lists depends on the argument:

  • Operators, for actions, conditions and numbers. On a number you can also just type the value.
  • Values, for every other argument (ships, wings, messages, events, sounds, and so on): the same choices as the right-click Replace Data menu. Where an argument also accepts text that isn't listed, such as a plain string or a message sender, you can type your own. Arguments that only take listed values, such as ships or events, can't be set to anything else. The current value starts highlighted.
  • An argument with nothing to list (a free-form string) opens a plain text edit instead.
ToDo this
Take the highlighted entryPress Enter or click it. Use Up/Down to move the highlight while you keep typing.
Keep what you typedPress Enter when nothing in the list matches, or click elsewhere. Clicking elsewhere only keeps an exact entry: a number, the full name of an operator or listed value, or your own text where the argument accepts it. Nothing is guessed.
CancelPress Escape.

Variables and containers are not in the search; use Replace Variable and Replace Container Data from the right-click menu.
